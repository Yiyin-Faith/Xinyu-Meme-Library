# 心语表情库使用说明

## Windows

运行 `npm run desktop:dist` 生成安装包，安装后从开始菜单或桌面快捷方式打开心语表情库。开发调试也可以运行 `npm run desktop:pack`，再双击 `release/PC/win-unpacked/xinyu-meme-library.exe`，或双击根目录的 `启动PC客户端.vbs`。关闭窗口会留在系统托盘，右击托盘可以退出；`Ctrl + Shift + P` 可以快速呼出窗口。

默认打开“图片库”的紧凑视图，图片库不会自动加入示例表情。右上角“添加图片”会直接打开系统选图，支持批量导入，选中后立即入库，无需先填标签或分类。点击卡片先打开预览，在预览中复制或分享；长按卡片（桌面端也可右键或点 `…`）才进入标题、标签、收藏夹和备注管理。GIF 和 WebP 使用保存原图流程，避免丢失动画。

底栏的“社区”默认展示三条本地 Mock 预设帖，用于验证浏览、点赞和发布入口；它们不会加入你的图片库，也不会联网。

## Android

运行 `npm run android:build`，把 `release/Android/Xinyu-Meme-Library-版本号-Android.apk` 传到手机并安装。当前构建使用 release 变体；未配置商店签名证书时会使用本机调试签名，因此可供个人安装和测试，发布应用商店前仍需配置正式签名。点击卡片先预览，再从预览中的“分享图片”打开系统分享面板。

## 电脑和手机互传

在“导入与同步”中导出完整备份，得到 `.puff.zip`。把它传到另一台设备，再在同一页面选择 ZIP 恢复。备份格式继续使用 `.puff.zip`，这是为了兼容以前导出的文件。

## 隐私

本地图片、标签、备注和收藏夹保存在当前设备。在线图库只有在主动进入“在线补充”时才访问；不需要网页服务，也没有账号云同步。
